# pixel-size
Pixel Size es un sandbox 2D de exploración, experimentación y caos. Cambia de escala libremente, desde pequeños objetos hasta personas, planetas, galaxias y el universo entero. Manipula la realidad, controla el tiempo, crea agujeros negros o provoca destrucción a tu gusto. Tú decides cómo jugar en este universo sin límites.
